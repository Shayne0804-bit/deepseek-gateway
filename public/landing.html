Fonctionnement

Ce qui se passe quand vous envoyez une requête.

01
Votre outilSDK · cURL · CLI
02
Clé dérivéesk-dsk-… · vlt_…
03
Passerellequotas · crédit · ledger
04
Fournisseurclé maîtresse, côté serveur

  1. 01 · Envoi

    Votre outil envoie la requête.

    SDK OpenAI, Anthropic Messages, cURL ou VALARIA Code : seule l’URL de base change. Le reste de votre code reste identique.

  2. 02 · Identification

    La passerelle vous reconnaît.

    La requête porte votre clé sk-dsk-… ou, depuis VALARIA Code, le jeton d’appareil vlt_…. Vous pouvez révoquer l’un ou l’autre sans couper vos autres accès.

  3. 03 · Contrôle

    Votre pass est vérifié.

    La passerelle contrôle la date de fin, le crédit restant, le nombre de requêtes par minute et les appels en parallèle. Si une limite est atteinte, vous recevez un message qui dit laquelle.

  4. 04 · Réponse

    La réponse revient avec vos compteurs à jour.

    Le modèle répond, en streaming si vous le demandez. Les en-têtes x-quota-… indiquent ce qu’il vous reste et l’appel s’ajoute à votre historique, avec son coût.

Sécurité et contrôle

Votre accès et votre budget restent sous contrôle.

Chaque accès a ses propres limites et peut être coupé à tout moment. Vous partagez l’usage de l’API sans jamais donner la clé du fournisseur.

01

Une clé par personne

Chaque personne ou chaque projet a sa propre clé, de 1 à 25 selon le pass. Vous la régénérez ou la révoquez quand vous voulez, sans toucher aux autres.

sk-dsk-…
sk-dsk-a91f…active sk-dsk-77c2…quota 82 % sk-dsk-e0b4…active
02

Des limites visibles

Crédit restant, plafond sur 5 heures et plafond sur 7 jours s’affichent dans votre espace.

x-quota-*
03

Le coût de chaque appel

Chaque requête est enregistrée avec son modèle, ses tokens et son coût. Vous voyez où part votre crédit, jour après jour.

ledger
04

Connexion par appareil

VALARIA Code ne vous demande jamais de clé API. Le terminal affiche un code, vous le comparez dans votre navigateur, puis vous approuvez l’appareil.

vlt_…
K7QM-4XTD▌code valable 10 minutes
05

Trois niveaux d’approbation

En Strict, vous validez chaque écriture et chaque commande. En Sécurisé, seulement les fichiers sensibles et les commandes risquées. En Accès total, l’agent ne demande rien. Ctrl+G passe de l’un à l’autre.

06

Appareils révocables

Vos terminaux connectés sont listés dans votre espace. Un ordinateur perdu ou prêté se déconnecte en un clic.

VALARIA Code

Un agent de code qui demande avant d’agir.

VALARIA Code s’ouvre en plein écran dans votre terminal. La conversation reste lisible, le diff reste affiché pendant tout le travail, et vous décidez de ce qui est écrit.

VALARIA Code · Focus01 / 05
Focus : la conversation à gauche, le diff toujours visible à droite.
01Il lit avant d’écrire

L’agent ouvre les fichiers utiles et les consignes du projet (AGENTS.md, VALARIA.md, CLAUDE.md) avant de proposer un changement.

02Le diff reste à l’écran

Vous voyez les fichiers modifiés et chaque ligne ajoutée ou supprimée, pendant tout le travail.

03Il se souvient du projet

La conversation est sauvegardée par dossier. Au lancement suivant, l’agent reprend là où vous vous étiez arrêtés.
